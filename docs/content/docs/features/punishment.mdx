# 処罰

LibertyBans が導入されている Velocity では、処罰と処罰の解除が Discord に報告されます。
処罰が確定した後に報告するため、他のプラグインによって取り消された処罰は報告されません。

## 処罰

BAN・ミュート・警告・キックが報告されます。

| 項目 | 内容 |
|------|------|
| 処罰 | 処罰の種類 (`BAN` / `MUTE` / `WARN` / `KICK`) |
| 期間 | 処罰の期間 (ISO-8601 形式。例: 7 日間は `PT168H`)。無期限の処罰とキックは `PT0S` です。 |
| 理由 | 処罰の理由 |

## 処罰の解除

処罰を解除すると、恩赦として報告されます。

| 項目 | 内容 |
|------|------|
| 恩赦 | 解除された処罰の種類 (例: `BAN`) |

## 表示

- メッセージの送信者には、処罰 (または解除) を行った人が表示されます。コンソールから実行された場合は、サービスアカウントとして表示されます。
- Embed の上部には、処罰された人が表示されます。IP アドレスに対する処罰の場合は、アドレスが表示されます。

Embed の色は処罰の種類ごとに異なります。
