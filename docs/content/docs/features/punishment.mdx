# 処罰

LibertyBans が導入されている Velocity では、処罰と処罰の解除が Discord に報告されます。
処罰が確定した後に報告するため、他のプラグインによって取り消された処罰は報告されません。

## 処罰

BAN・ミュート・警告・キックが報告されます。

| 項目 | 内容 |
|------|------|
| 処罰 | 処罰の種類 (`BAN` / `MUTE` / `WARN` / `KICK`) |
| 期間 | 処罰の期間 (例: `7日`、`1日 12時間`)。無期限の処罰は `無期限` です。キックは期間を持たないため、この項目は表示されません。 |
| 理由 | 処罰の理由 |

## 処罰の解除

処罰を解除すると、恩赦として報告されます。

| 項目 | 内容 |
|------|------|
| 恩赦 | 解除された処罰の種類 (例: `BAN`) |

## 表示

- メッセージの送信者には、処罰 (または解除) を行った人が表示されます。コンソールから実行された場合は、サービスアカウントとして表示されます。
- Embed の上部には、処罰された人が表示されます。IP アドレスに対する処罰の場合は、アドレスは表示されず、`IP BANにつき非表示` のように表示されます。

Embed の色は処罰の種類ごとに異なります。

## チケットのクローズ

処罰の理由に `close #番号` を含めると、処罰が確定した後に [MoripaUtils](https://github.com/morinoparty/moripa-utils) のチケットをクローズします。

```text
/ban Steve 7d 建物破壊および窃盗 close #11
```

- `close #番号` は、処罰が確定する前に理由から取り除かれます。LibertyBans には `close #番号` を除いた理由 (上の例では「建物破壊および窃盗」) が保存され、Discord にもその理由が表示されます。
- クローズの理由は「対応完了」(`done`) になり、`close #番号` を除いた理由がチケットにコメントとして書き込まれます。
- `close #2 close #3` のように、複数のチケットを指定できます。全角のスペース・`＃`・数字も使えます (例: `close　＃１１`)。
- チケットは、処罰したプレイヤーとしてクローズされます。プロキシにいる場合は `moripautils.ticket.staff` 権限で運営かどうかを判定し、それ以外の場合 (コンソールを含む) は運営として扱います。コンソールの場合の名前は、設定の `webhook.serviceAccountName` です。
- クローズの結果は、処罰したプレイヤーにチャットで表示されます。プロキシにいない場合やコンソールの場合は、ログに出力されます。
- Velocity 版の MoripaUtils が導入されていない場合や、MoripaUtils がチケットを扱えない場合 (共有データベースに MySQL を使っていない場合) は、チケットはクローズされません。
- 他のプラグインによって取り消された処罰では、チケットはクローズされません。
