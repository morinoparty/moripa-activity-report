# 土地保護の削除

GriefPrevention が導入されている Paper サーバーでは、`/deleteclaim` に削除の理由を付けて実行できるようになります。
土地保護を削除すると、理由と一緒に Discord に報告されます。

## 使い方

削除したい土地保護の中に立ち、理由を付けて `/deleteclaim` を実行します。

```text
/deleteclaim ban対象者の保護地である為
```

理由を省略した場合は削除されず、理由の入力を求めるメッセージが表示されます。
削除そのものは GriefPrevention が行うため、権限 (`griefprevention.deleteclaims`) や、サブディビジョンを含む土地保護の確認などは GriefPrevention の動作と同じです。
サブディビジョンを含む土地保護では、1 回目の実行では警告だけが表示されるため、もう一度理由を付けて実行してください。

## チケットのクローズ

理由に `close #番号` を含めると、削除と同時に [MoripaUtils](https://github.com/morinoparty/moripa-utils) のチケットをクローズします。

```text
/deleteclaim 長期間放置 close #2
```

- クローズの理由は「対応完了」(`done`) になります。
- 理由から `close #番号` を取り除いた残り (上の例では「長期間放置」) が、チケットにコメントとして書き込まれます。
- `close #2 close #3` のように、複数のチケットを指定できます。
- チケットは、実行したプレイヤーとしてクローズされます。`moripautils.ticket.staff` 権限を持たない場合は、自分のチケットしかクローズできません。
- クローズの結果は、実行したプレイヤーにチャットで表示されます。
- MoripaUtils が導入されていない場合は、チケットはクローズされません。

## 報告の項目

| 項目 | 内容 |
|------|------|
| 処理 | `土地保護削除` |
| 座標 | 土地保護の北西の角の座標 (例: `x: 532 z: 1057`) |
| 最終ログイン | 土地保護の持ち主が最後にサーバーにいた日時 (例: `6日前`)。GriefPrevention が土地保護の期限切れの判定に使う値と同じです。 |
| 理由 | `/deleteclaim` に入力した理由 |

Embed の上部には土地保護の持ち主が、メッセージの送信者には削除したプレイヤーが表示されます。
