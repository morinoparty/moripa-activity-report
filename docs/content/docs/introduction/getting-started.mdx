# はじめに

このページでは、MoripaActivityReport をサーバーに導入し、Discord に報告を送れるようにするまでの手順を説明します。

## 動作環境

| 環境 | 必要なもの | 連携するプラグイン (任意) |
|------|-----------|--------------------------|
| Paper | Paper 26.2 以降、Java 25 | GriefPrevention (土地保護の削除の報告)、MoripaUtils (チケットのクローズ) |
| Velocity | Velocity、Java 25 | LibertyBans (処罰の報告)、MoripaUtils (チケットのクローズ) |

連携するプラグインはどれも任意です。導入されていないプラグインに関する機能だけが無効になります。

## 導入

1. [GitHub Releases](https://github.com/morinoparty/moripa-activity-report/releases) から JAR をダウンロードします。
    - Paper: `MoripaActivityReport-paper-<バージョン>.jar`
    - Velocity: `MoripaActivityReport-velocity-<バージョン>.jar`
2. JAR を各サーバーの `plugins/` に置き、サーバーを起動します。初回起動時に `config.json` が作成されます。
3. `config.json` の `webhook.url` に Discord Webhook の URL を設定し、`/mar reload` (Paper) または `/marv reload` (Velocity) で反映します。

設定の項目は [設定](/config) を参照してください。

Paper 版は、JAR に同梱していない依存ライブラリを初回起動時にダウンロードします。
仕組みについては [実行時ライブラリ](/development/runtime-libraries) を参照してください。

## ソースからのビルド

ビルドには Java 25 が必要です。[Task](https://taskfile.dev/) を使う場合は `task build` でも実行できます。

```bash
./gradlew build -x test
```

Paper 向けの JAR は `paper/build/libs/*-all.jar`、Velocity 向けの JAR は `velocity/build/libs/*-all.jar` に出力されます。

開発用の Paper サーバーは、次のコマンドで起動できます。

```bash
./gradlew :paper:runServer
```

ドキュメントサイトのビルドには Node.js 26 以降と pnpm 10 以降が必要です。詳しくは [ドキュメントサイト](/development/docs-site) を参照してください。
